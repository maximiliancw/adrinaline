# WP2 Graph: relations, `adr graph`, renumber — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Relations between ADRs (supersedes, amends, depends-on, relates-to) backed by one in-memory graph, with `supersede`, `link`, `unlink`, `graph` (text/mermaid/dot/json), `renumber`, derived inverses in `show`, and relation checks.

**Architecture:** `graph.AdrGraph` is built from the loaded ADR list. It owns edges, derived inverses, traversal, cycle detection and renderers. `repo` gains relation operations that validate against the graph and write files. `check` gains relation rules. `cli` gains thin commands.

**Tech Stack:** Python 3.14 stdlib (`graphlib`, `collections`), existing modules from WP1.

**Spec:** `docs/SPEC.md` (§8 Relations and Graph model, §9 rows new/supersede/link/unlink/graph/renumber/show, §11 relation codes, §16 criteria 8, 9, 11, 16, 17, 18). Requires WP1 to be complete.

## Global Constraints

- Python `>=3.14`; no new runtime dependencies (graph code uses dicts and stdlib `graphlib`).
- Only forward relations are stored, on the ADR that declares them; `superseded-by` is the one stored inverse, and `adr supersede` writes both sides. `relates-to` is stored once.
- Commands that add a link change only the declaring ADR's file (`supersede` also changes the superseded one).
- `supersedes` targets must be `accepted` unless `--force`; `supersedes` and `depends-on` must stay acyclic; no self-relations.
- With `--json`, stdout carries exactly one JSON document. Exit codes 0/1/2/3 as in WP1.
- Every write goes through `repo.atomic_write`/`repo.save`. No git writes.
- English everywhere; no AI attribution; Conventional Commits. Lint, format, type check and tests pass after every task.

## Review Focus

1. A relation to a number that does not exist (hand edit) must not crash `show`, `graph` or `prime`; it renders as `NNNN (missing)` → test in Task 1.
2. `relates-to` stored on either side must show up on both ADRs in `show`, and traversing it must not loop → test in Task 1.
3. `adr link` when the link already exists (or the symmetric `relates-to` is stored on the other side) must be a no-op, not a duplicate entry → test in Task 3.
4. `adr renumber` must refuse a target number that exists and must not leave both the old and new file behind → test in Task 4.
5. Titles containing `"` must not break Mermaid or DOT output → test in Task 2.

```python
"""In-memory ADR graph: typed edges, derived inverses, traversal and rendering."""

from collections import defaultdict, deque
from dataclasses import dataclass
from graphlib import CycleError, TopologicalSorter

from adrinaline.model import INVERSE, Adr, Status

FORWARD = ("supersedes", "amends", "depends-on", "relates-to")
ACYCLIC = ("supersedes", "depends-on")
IMPACT = ("depends-on", "amends")


@dataclass(frozen=True)
class Edge:
    src: int
    dst: int
    relation: str


@dataclass
class Subgraph:
    nodes: list[int]
    edges: list[Edge]
    steps: list[tuple[int, int, str]]  # (parent, child, relation as seen from the parent)


class AdrGraph:
    def __init__(self, adrs: list[Adr]) -> None:
        self.adrs = adrs
        self.nodes: dict[int, Adr] = {}
        for adr in adrs:
            self.nodes.setdefault(adr.number, adr)
        edges = [
            Edge(adr.number, n, relation)
            for adr in adrs
            for relation in FORWARD
            for n in adr.relations.get(relation, [])
        ]
        edges += [
            Edge(n, adr.number, "supersedes")
            for adr in adrs
            for n in adr.relations.get("superseded-by", [])
        ]
        self.edges = list(dict.fromkeys(edges))

    def label(self, number: int) -> str:
        adr = self.nodes.get(number)
        return f"{number:04d} {adr.title}" if adr else f"{number:04d} (missing)"

    def status(self, number: int) -> str:
        adr = self.nodes.get(number)
        return adr.status.value if adr else "missing"

    def related(self, number: int) -> dict[str, list[int]]:
        found: dict[str, set[int]] = defaultdict(set)
        for edge in self.edges:
            if edge.src == number:
                found[edge.relation].add(edge.dst)
            if edge.dst == number:
                found[INVERSE[edge.relation]].add(edge.src)
        return {name: sorted(numbers) for name, numbers in sorted(found.items())}

    def in_force(self) -> list[Adr]:
        return [
            adr
            for number, adr in sorted(self.nodes.items())
            if adr.status is Status.ACCEPTED and not self.related(number).get("superseded-by")
        ]

    def successor(self, number: int) -> int:
        seen = {number}
        while successors := self.related(number).get("superseded-by"):
            number = successors[-1]
            if number in seen:
                break
            seen.add(number)
        return number

    def cycle(self, relation: str, extra: Edge | None = None) -> list[int] | None:
        sorter: TopologicalSorter[int] = TopologicalSorter()
        for edge in [*self.edges, *([extra] if extra else [])]:
            if edge.relation == relation:
                sorter.add(edge.src, edge.dst)
        try:
            sorter.prepare()
        except CycleError as exc:
            return list(exc.args[1])
        return None

    def reachable(
        self,
        start: int,
        relations: tuple[str, ...] = FORWARD,
        *,
        reverse: bool = False,
        depth: int | None = None,
    ) -> Subgraph:
        sub = Subgraph([start], [], [])
        seen = {start}
        queue = deque([(start, 0)])
        while queue:
            current, level = queue.popleft()
            if depth is not None and level >= depth:
                continue
            for edge in self.edges:
                if edge.relation not in relations or edge in sub.edges:
                    continue
                ahead, behind = (edge.src, edge.dst) if reverse else (edge.dst, edge.src)
                if behind == current:
                    child, name = ahead, INVERSE[edge.relation] if reverse else edge.relation
                elif edge.relation == "relates-to" and ahead == current:
                    child, name = behind, "relates-to"
                else:
                    continue
                sub.edges.append(edge)
                sub.steps.append((current, child, name))
                if child not in seen:
                    seen.add(child)
                    sub.nodes.append(child)
                    queue.append((child, level + 1))
        return sub
```

```python
_FILL = {
    "proposed": "fill:#fff4cc",
    "accepted": "fill:#d9f2d9",
    "rejected": "fill:#f2d9d9",
    "deprecated": "fill:#e6e6e6",
    "superseded": "fill:#e6e6e6,stroke-dasharray:4 2",
    "missing": "fill:#ffffff,stroke-dasharray:2 2",
}


def all_nodes(graph: AdrGraph) -> list[int]:
    return sorted({*graph.nodes, *(e.src for e in graph.edges), *(e.dst for e in graph.edges)})


def render_text(graph: AdrGraph, sub: Subgraph | None) -> str:
    if sub is None:
        lines: list[str] = []
        for number in sorted(graph.nodes):
            lines.append(f"{graph.label(number)} [{graph.status(number)}]")
            lines += [
                f"  {e.relation} -> {graph.label(e.dst)}" for e in graph.edges if e.src == number
            ]
        return "\n".join(lines)
    children: dict[int, list[tuple[str, int]]] = defaultdict(list)
    for parent, child, relation in sub.steps:
        children[parent].append((relation, child))
    root = sub.nodes[0]
    lines = [f"{graph.label(root)} [{graph.status(root)}]"]
    seen = {root}

    def walk(number: int, depth: int) -> None:
        for relation, child in children[number]:
            repeat = child in seen
            suffix = " (see above)" if repeat else f" [{graph.status(child)}]"
            lines.append(f"{'  ' * depth}{relation} -> {graph.label(child)}{suffix}")
            if not repeat:
                seen.add(child)
                walk(child, depth + 1)

    walk(root, 1)
    return "\n".join(lines)


def render_mermaid(graph: AdrGraph, nodes: list[int], edges: list[Edge]) -> str:
    lines = ["flowchart LR"]
    for n in nodes:
        label = graph.label(n).replace('"', "#quot;")
        lines.append(f'  A{n}["{label}"]:::{graph.status(n)}')
    for e in edges:
        arrow = "---" if e.relation == "relates-to" else "-->"
        lines.append(f"  A{e.src} {arrow}|{e.relation}| A{e.dst}")
    lines += [f"  classDef {status} {style}" for status, style in _FILL.items()]
    return "\n".join(lines)


def _quote(text: str) -> str:
    return '"' + text.replace("\\", "\\\\").replace('"', '\\"') + '"'


def render_dot(graph: AdrGraph, nodes: list[int], edges: list[Edge]) -> str:
    lines = ["digraph adr {", "  rankdir=LR;", '  node [shape=box, style="rounded,filled"];']
    for n in nodes:
        fill = _FILL[graph.status(n)].split(",")[0].removeprefix("fill:")
        lines.append(f"  n{n} [label={_quote(graph.label(n))}, fillcolor={_quote(fill)}];")
    for e in edges:
        extra = ", dir=none" if e.relation == "relates-to" else ""
        lines.append(f"  n{e.src} -> n{e.dst} [label={_quote(e.relation)}{extra}];")
    lines.append("}")
    return "\n".join(lines)


def graph_data(
    graph: AdrGraph,
    nodes: list[int],
    edges: list[Edge],
    ranks: dict[int, float] | None = None,
) -> dict:
    node_rows = []
    for n in nodes:
        adr = graph.nodes.get(n)
        row = {
            "number": n,
            "id": f"{n:04d}",
            "title": adr.title if adr else None,
            "status": graph.status(n),
        }
        if ranks is not None:
            row["rank"] = ranks.get(n, 0.0)
        node_rows.append(row)
    return {
        "nodes": node_rows,
        "edges": [{"from": e.src, "to": e.dst, "relation": e.relation} for e in edges],
    }
```

def _cycle_error(relation: str, cycle: list[int]) -> AdrError:
    path = " -> ".join(f"{n:04d}" for n in cycle)
    return AdrError("cycle", f"this would create a {relation} cycle: {path}", cycle=cycle)


def supersede(graph: AdrGraph, old: Adr, new: Adr, *, force: bool, today: dt.date) -> None:
    if old.number == new.number:
        raise AdrError("self-relation", f"{old.id} cannot supersede itself")
    if old.status is not Status.ACCEPTED and not force:
        raise AdrError(
            "invalid-transition",
            f"{old.id} is {old.status}; only accepted ADRs can be superseded (use --force to repair)",
            current=old.status.value,
            requested=Status.SUPERSEDED.value,
        )
    if cycle := graph.cycle("supersedes", Edge(new.number, old.number, "supersedes")):
        raise _cycle_error("supersedes", cycle)
    set_relation(new, "supersedes", [*new.relations["supersedes"], old.number])
    set_relation(old, "superseded-by", [*old.relations["superseded-by"], new.number])
    set_status(old, Status.SUPERSEDED, today)
    save(new)
    save(old)


def link(graph: AdrGraph, src: Adr, relation: str, dst: Adr) -> bool:
    if relation not in LINKABLE:
        raise AdrError("bad-relation", f"cannot link with {relation!r}; use one of {LINKABLE}")
    if src.number == dst.number:
        raise AdrError("self-relation", f"{src.id} cannot {relation} itself")
    if relation in ACYCLIC and (cycle := graph.cycle(relation, Edge(src.number, dst.number, relation))):
        raise _cycle_error(relation, cycle)
    if dst.number in src.relations[relation]:
        return False
    if relation == "relates-to" and src.number in dst.relations["relates-to"]:
        return False
    set_relation(src, relation, [*src.relations[relation], dst.number])
    save(src)
    return True


def unlink(src: Adr, relation: str, dst: Adr) -> list[Adr]:
    changed = []
    pairs = [(src, dst), (dst, src)] if relation == "relates-to" else [(src, dst)]
    for holder, target in pairs:
        if target.number in holder.relations[relation]:
            set_relation(holder, relation, [n for n in holder.relations[relation] if n != target.number])
            save(holder)
            changed.append(holder)
    return changed

def _relations(s: AdrSet, graph: AdrGraph) -> list[Finding]:
    found: list[Finding] = []
    for adr in s.adrs:
        path = str(adr.path)
        for name in STORED_RELATIONS:
            for n in adr.relations[name]:
                if n == adr.number:
                    found.append(Finding("self-relation", "error", path, f"{adr.id} {name} itself"))
                elif n not in graph.nodes:
                    found.append(
                        Finding("dangling-relation", "error", path, f"{adr.id} {name} {n:04d}, which does not exist")
                    )
        for name, inverse in (("supersedes", "superseded-by"), ("superseded-by", "supersedes")):
            for n in adr.relations[name]:
                other = graph.nodes.get(n)
                if other and other.number != adr.number and adr.number not in other.relations[inverse]:
                    found.append(
                        Finding(
                            "asymmetric-relation",
                            "error",
                            path,
                            f"{adr.id} {name} {other.id}, but {other.id} has no {inverse}: [{adr.number}]",
                        )
                    )
        if bool(adr.relations["superseded-by"]) != (adr.status is Status.SUPERSEDED):
            found.append(
                Finding(
                    "status-mismatch",
                    "error",
                    path,
                    f"{adr.id}: status {adr.status} does not match superseded-by {adr.relations['superseded-by']}",
                )
            )
    for relation in ACYCLIC:
        if cycle := graph.cycle(relation):
            chain = " -> ".join(f"{n:04d}" for n in cycle)
            found.append(Finding("cycle", "error", "", f"{relation} cycle: {chain}"))
    return found

def renumber(s: AdrSet, adr: Adr, to: int) -> tuple[Path, list[Adr]]:
    if to in s.numbers or to < 1:
        raise AdrError("exists", f"{to:04d} is already taken or invalid", number=to)
    old_name = adr.path.name
    new_path = adr.path.with_name(f"{to:04d}-{adr.slug}.md")
    unique = sum(1 for a in s.adrs if a.number == adr.number) == 1
    changed: list[Adr] = []
    for other in s.adrs:
        touched = False
        if unique and other is not adr:
            for name in STORED_RELATIONS:
                if adr.number in other.relations[name]:
                    set_relation(other, name, [to if n == adr.number else n for n in other.relations[name]])
                    touched = True
        if old_name in other.body:
            other.body = other.body.replace(old_name, new_path.name)
            touched = True
        if touched and other is not adr:
            save(other)
            changed.append(other)
    atomic_write(new_path, render(adr.meta, adr.body))
    adr.path.unlink()
    return new_path, changed
