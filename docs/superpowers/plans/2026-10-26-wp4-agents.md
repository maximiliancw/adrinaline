# WP4 Agents: rank, `adr graph --rank`, `adr prime [--budget N]` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give agents a compact, context-aware briefing: PageRank over the ADR graph, a ranked graph view, and `adr prime` with an optional word budget filled by score from a heap.

**Architecture:** `AdrGraph.rank()` is a hand-rolled PageRank (power iteration). `prime.py` scores ADRs in force (rank, scope hit in the working tree, recency) and pops them from a `heapq` heap until the budget is used. `cli` renders the briefing as Markdown or JSON.

**Tech Stack:** Python 3.14 stdlib (`heapq`, `collections.Counter`), existing modules.

**Spec:** `docs/SPEC.md` (§8 Rank, §9 rows graph/prime, §12 `adr prime`, §16 criteria 14, 22, 23). Requires WP1–WP3.

## Global Constraints

- PageRank: damping 0.85, stop when the L1 change is below 1e-9 or after 100 iterations; `depends-on` and `amends` pass weight to their target, `relates-to` both ways, `supersedes` is excluded; ranks sum to 1.
- Score = 0.5 · rank normalised to 0–1 + 0.3 · scope hit (working-tree changes from `git status --porcelain`) + 0.2 · recency (linear between oldest and newest `date`). Weights are constants, not configuration.
- `--budget N` limits only the "Decisions in force" section to about N words; header, proposed ADRs and the usage rules are always printed.
- `prime` is a read command: it accepts `--at`.
- With `--json`, stdout carries exactly one JSON document. Exit codes 0/1/2/3.
- English everywhere; no AI attribution; Conventional Commits. Lint, format, type check and tests pass after every task.

## Review Focus

1. An empty ADR set (only a template, or ADRs that are all proposed) must not divide by zero in rank or recency → test in Task 1 and Task 2.
2. All ADRs sharing the same date must give every one recency 1.0, not a division error → test in Task 2.
3. A budget smaller than any single entry must print no entries and an accurate omitted count, not crash → test in Task 2.
4. Relations to missing ADRs must not distort or crash the rank computation → test in Task 1.
5. `adr prime --at REF` must not read working-tree changes from the current checkout (scope hits would be meaningless) → test in Task 2.

```python
    def rank(
        self, damping: float = 0.85, tolerance: float = 1e-9, max_iterations: int = 100
    ) -> dict[int, float]:
        nodes = sorted(self.nodes)
        if not nodes:
            return {}
        size = len(nodes)
        targets: dict[int, list[int]] = {n: [] for n in nodes}
        for edge in self.edges:
            if edge.src not in targets or edge.dst not in targets:
                continue
            if edge.relation in IMPACT:
                targets[edge.src].append(edge.dst)
            elif edge.relation == "relates-to":
                targets[edge.src].append(edge.dst)
                targets[edge.dst].append(edge.src)
        ranks = dict.fromkeys(nodes, 1 / size)
        for _ in range(max_iterations):
            dangling = sum(ranks[n] for n in nodes if not targets[n])
            fresh = dict.fromkeys(nodes, (1 - damping) / size + damping * dangling / size)
            for n in nodes:
                for target in targets[n]:
                    fresh[target] += damping * ranks[n] / len(targets[n])
            change = sum(abs(fresh[n] - ranks[n]) for n in nodes)
            ranks = fresh
            if change < tolerance:
                break
        return ranks
```

```python
"""Agent briefing for `adr prime`: decisions in force, proposals and usage rules."""

import heapq
from collections import Counter
from dataclasses import dataclass
from pathlib import PurePosixPath

from adrinaline.graph import AdrGraph
from adrinaline.model import Adr, Status

RULES = """\
- Before changing code, run `adr for <path>` and follow the ADRs it lists.
- Write an ADR for decisions that are expensive to reverse: architecture, dependencies, data formats, public interfaces, security. Not for routine choices.
- New ADR: `adr new "Title" --body-file -` with Context and Problem Statement, Considered Options, Decision Outcome and Consequences on stdin.
- Never rewrite an accepted decision: `adr new "…" --supersedes N` replaces it, `adr new "…" --amends N` changes part of it.
- Look things up: `adr show N`, `adr list --status accepted`, `adr graph N`, `adr graph N --reverse`.
- Run `adr check` before you finish. Every command accepts `--json`."""


def _words(text: str) -> int:
    return len(text.split())


def entry(graph: AdrGraph, adr: Adr) -> str:
    related = graph.related(adr.number)
    links = "; ".join(
        f"{name} " + ", ".join(f"{n:04d}" for n in related[name])
        for name in ("depends-on", "amends")
        if related.get(name)
    )
    tags = f" [{', '.join(adr.tags)}]" if adr.tags else ""
    return f"- {adr.id} {adr.title}{tags}" + (f" ({links})" if links else "")


def scores(graph: AdrGraph, adrs: list[Adr], changed: list[str]) -> dict[int, float]:
    ranks = graph.rank()
    top = max(ranks.values(), default=0.0) or 1.0
    days = [adr.date.toordinal() for adr in adrs]
    low, high = min(days, default=0), max(days, default=0)
    paths = [PurePosixPath(p) for p in changed]
    result: dict[int, float] = {}
    for adr in adrs:
        hit = any(p.full_match(glob) for p in paths for glob in adr.scope)
        recency = (adr.date.toordinal() - low) / (high - low) if high > low else 1.0
        result[adr.number] = 0.5 * ranks.get(adr.number, 0.0) / top + 0.3 * hit + 0.2 * recency
    return result


def select(
    graph: AdrGraph, adrs: list[Adr], changed: list[str], budget: int
) -> tuple[list[Adr], int]:
    points = scores(graph, adrs, changed)
    heap = [(-points[adr.number], adr.number, i) for i, adr in enumerate(adrs)]
    heapq.heapify(heap)
    chosen: list[Adr] = []
    used = 0
    while heap:
        _, _, i = heapq.heappop(heap)
        cost = _words(entry(graph, adrs[i]))
        if used + cost <= budget:
            chosen.append(adrs[i])
            used += cost
    chosen.sort(key=lambda adr: adr.number)
    return chosen, len(adrs) - len(chosen)


@dataclass
class Briefing:
    markdown: str
    shown: list[Adr]
    omitted: int
    proposed: list[Adr]
    counts: dict[str, int]


def briefing(
    graph: AdrGraph, dir_label: str, changed: list[str], budget: int | None = None
) -> Briefing:
    in_force = graph.in_force()
    proposed = [adr for _, adr in sorted(graph.nodes.items()) if adr.status is Status.PROPOSED]
    if budget is None:
        shown, omitted = in_force, 0
    else:
        shown, omitted = select(graph, in_force, changed, budget)
    counter = Counter(adr.status.value for adr in graph.adrs)
    counts = {s.value: counter[s.value] for s in Status if counter[s.value]}
    summary = ", ".join(f"{n} {status}" for status, n in counts.items()) or "none yet"
    parts = [
        "# ADR briefing",
        f"ADRs live in `{dir_label}`: {summary}.",
        "## Decisions in force",
        "\n".join(entry(graph, adr) for adr in shown) or "None.",
    ]
    if omitted:
        parts.append(f"{omitted} more in force: `adr list --status accepted`")
    parts += [
        "## Proposed",
        "\n".join(entry(graph, adr) for adr in proposed) or "None.",
        "## Using adr",
        RULES,
    ]
    return Briefing("\n\n".join(parts), shown, omitted, proposed, counts)
```
