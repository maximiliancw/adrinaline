# WP1 Core: model, storage, basic commands — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working `adr` CLI that initialises an ADR directory, creates, shows, lists and indexes ADRs, changes their status, and runs file-level checks, in human and `--json` mode.

**Architecture:** `frontmatter` (ruamel round-trip) → `model` (pydantic validation, `Adr` dataclass) → `repo` (directory discovery, loading, writing) → `check` (findings) → `output` (human/JSON) → `cli` (argparse, one `cmd_<name>` per command). `cli` holds no domain logic.

**Tech Stack:** Python 3.14, uv (uv_build backend), pydantic 2, ruamel.yaml, argparse, pytest, ruff, ty.

**Spec:** `docs/SPEC.md` (§3, §4, §5, §6, §7, §9 rows init/new/show/list/index/accept/reject/deprecate/check/skill, §11 file-level codes, §12 JSON and exit codes, §14, §16 criteria 1–4, 6, 7, 12, 13).

## Global Constraints

- Python `>=3.14`; runtime dependencies only `pydantic` and `ruamel.yaml`; CLI uses stdlib `argparse`.
- Console scripts `adr` and `adrinaline`, both `adrinaline.cli:run`; `python -m adrinaline` works too.
- Command handlers are named `cmd_<name>`; `cli.py` contains no domain logic.
- With `--json`, stdout carries exactly one JSON document; diagnostics go to stderr.
- Exit codes: 0 success, 1 `check` found problems, 2 usage error (argparse), 3 domain error.
- Every file write goes through `repo.atomic_write` (temp file + `os.replace`); new ADR files use exclusive create.
- The tool never runs a git command that writes (`add`, `commit`, `fetch`, `checkout`, …).
- English everywhere; no AI attribution in code, comments or commit messages; Conventional Commits.
- `uv run ruff check`, `uv run ruff format --check`, `uv run ty check`, `uv run pytest` pass at the end of every task.

## Review Focus

1. A body containing a `---` line (Markdown horizontal rule) must not be mistaken for the end of the frontmatter → test in Task 2.
2. Non-ASCII titles (`Über-Caching für APIs`) must produce an ASCII slug (`uber-caching-fur-apis`), and a title made only of punctuation must not produce an empty filename → test in Task 4.
3. Running `adr` from a subdirectory or from outside any git repository must find (or clearly fail to find) the ADR directory → tests in Task 4 and Task 6.
4. `adr show --raw` and `adr skill` must print file content byte-for-byte (no extra trailing newline) → test in Task 6.
5. A `|` in a title must not break the `adr index` table → test in Task 6.

```python
"""Split, parse and render Markdown files with YAML frontmatter (round-trip safe)."""

from collections.abc import Iterable
from io import StringIO

from ruamel.yaml import YAML
from ruamel.yaml.comments import CommentedMap, CommentedSeq
from ruamel.yaml.error import YAMLError


class FrontmatterError(ValueError):
    """The file has no valid YAML frontmatter mapping."""


def _yaml() -> YAML:
    yaml = YAML()  # round-trip mode: keeps comments, key order and quoting
    yaml.preserve_quotes = True
    yaml.width = 4096
    yaml.indent(mapping=2, sequence=4, offset=2)
    return yaml


def split(text: str) -> tuple[CommentedMap, str]:
    lines = text.splitlines(keepends=True)
    if not lines or lines[0].rstrip("\r\n") != "---":
        raise FrontmatterError("missing frontmatter (file must start with '---')")
    for end, line in enumerate(lines[1:], start=1):
        if line.rstrip("\r\n") == "---":
            try:
                data = _yaml().load("".join(lines[1:end]))
            except YAMLError as exc:
                raise FrontmatterError(f"invalid YAML: {exc}") from exc
            if data is None:
                data = CommentedMap()
            if not isinstance(data, CommentedMap):
                raise FrontmatterError("frontmatter is not a mapping")
            return data, "".join(lines[end + 1 :])
    raise FrontmatterError("unterminated frontmatter (no closing '---')")


def render(meta: CommentedMap, body: str) -> str:
    if not meta:
        return f"---\n---\n{body}"
    buffer = StringIO()
    _yaml().dump(meta, buffer)
    return f"---\n{buffer.getvalue()}---\n{body}"


def flow(items: Iterable) -> CommentedSeq:
    seq = CommentedSeq(items)
    seq.fa.set_flow_style()
    return seq
```

`src/adrinaline/model.py`:

```python
"""ADR domain model: statuses, relations, errors and parsing."""

import datetime as dt
import re
from dataclasses import dataclass
from enum import StrEnum
from pathlib import Path, PurePosixPath
from typing import Any

from pydantic import BaseModel, ConfigDict, Field, ValidationError, field_validator
from ruamel.yaml.comments import CommentedMap

from adrinaline.frontmatter import FrontmatterError, split

FILENAME_RE = re.compile(r"^(\d{4,})-([a-z0-9]+(?:-[a-z0-9]+)*)\.md$")


class Status(StrEnum):
    PROPOSED = "proposed"
    ACCEPTED = "accepted"
    REJECTED = "rejected"
    DEPRECATED = "deprecated"
    SUPERSEDED = "superseded"


TRANSITIONS = frozenset(
    {
        (Status.PROPOSED, Status.ACCEPTED),
        (Status.PROPOSED, Status.REJECTED),
        (Status.ACCEPTED, Status.DEPRECATED),
        (Status.ACCEPTED, Status.SUPERSEDED),
    }
)

STORED_RELATIONS = ("supersedes", "superseded-by", "amends", "depends-on", "relates-to")
LINKABLE = ("amends", "depends-on", "relates-to")
INVERSE = {
    "supersedes": "superseded-by",
    "amends": "amended-by",
    "depends-on": "dependency-of",
    "relates-to": "relates-to",
}


class AdrError(Exception):
    """A domain error with a stable machine-readable code (exit code 3)."""

    def __init__(self, code: str, message: str, **details: Any) -> None:
        super().__init__(message)
        self.code = code
        self.message = message
        self.details = details


@dataclass(frozen=True)
class Finding:
    code: str
    severity: str  # "error" or "warning"
    path: str
    message: str


class Frontmatter(BaseModel):
    model_config = ConfigDict(extra="allow")

    status: Status
    date: dt.date
    tags: list[str] = []
    scope: list[str] = []
    supersedes: list[int] = []
    superseded_by: list[int] = Field(default=[], alias="superseded-by")
    amends: list[int] = []
    depends_on: list[int] = Field(default=[], alias="depends-on")
    relates_to: list[int] = Field(default=[], alias="relates-to")

    @field_validator("scope")
    @classmethod
    def _relative_globs(cls, globs: list[str]) -> list[str]:
        for glob in globs:
            if glob.startswith("/") or ".." in PurePosixPath(glob).parts:
                raise ValueError(f"scope glob must be repository-relative: {glob}")
        return globs


_FIELD_CODES = {"status": "bad-status", "date": "bad-date", "scope": "bad-scope"}


def _error_code(error: dict) -> str:
    if error["type"] == "missing":
        return "missing-field"
    return _FIELD_CODES.get(str(error["loc"][0]), "bad-field")


@dataclass
class Adr:
    number: int
    slug: str
    path: Path
    title: str
    status: Status
    date: dt.date
    tags: list[str]
    scope: list[str]
    relations: dict[str, list[int]]
    meta: CommentedMap
    body: str
    text: str

    @property
    def id(self) -> str:
        return f"{self.number:04d}"


def parse_adr(path: Path, text: str) -> Adr:
    match = FILENAME_RE.match(path.name)
    if not match:
        raise AdrError("bad-filename", f"{path.name}: expected NNNN-slug.md", path=str(path))
    try:
        meta, body = split(text)
    except FrontmatterError as exc:
        raise AdrError("no-frontmatter", f"{path.name}: {exc}", path=str(path)) from exc
    try:
        front = Frontmatter.model_validate(dict(meta))
    except ValidationError as exc:
        first = exc.errors()[0]
        where = ".".join(str(part) for part in first["loc"])
        raise AdrError(
            _error_code(first), f"{path.name}: {where}: {first['msg']}", path=str(path)
        ) from exc
    title = next((line[2:].strip() for line in body.splitlines() if line.startswith("# ")), "")
    if not title:
        raise AdrError("no-title", f"{path.name}: no '# ' title heading", path=str(path))
    relations = {name: list(getattr(front, name.replace("-", "_"))) for name in STORED_RELATIONS}
    return Adr(
        number=int(match[1]),
        slug=match[2],
        path=path,
        title=title,
        status=front.status,
        date=front.date,
        tags=front.tags,
        scope=front.scope,
        relations=relations,
        meta=meta,
        body=body,
        text=text,
    )
```

```markdown
## Considered Options

* Architecture Decision Records (ADRs) in MADR 4 format, managed with `adr`
* Decisions kept only in issues, wiki pages or commit messages

## Decision Outcome

Chosen option: "ADRs in MADR 4 format, managed with `adr`", because they live next to the code, are reviewed like code, and can be queried by humans and agents.

* Each ADR is a Markdown file `NNNN-slug.md` in this directory, with YAML frontmatter for status, date and relations.
* Accepted ADRs are immutable except for their status and relations. A changed decision gets a new ADR that supersedes or amends the old one.
* `adr check` passes before changes are merged.

### Consequences

* Good, because decisions and their reasons are versioned with the code.
* Bad, because writing an ADR takes time, so ADRs stay short.
```

```python
"""Read-only wrappers around the git executable. Never stage, commit or fetch."""

import subprocess
from pathlib import Path


def run(args: list[str], cwd: Path, stdin: str | None = None) -> str | None:
    try:
        proc = subprocess.run(
            ["git", "-c", "core.quotePath=false", *args],
            cwd=cwd,
            input=stdin,
            capture_output=True,
            text=True,
        )
    except FileNotFoundError:
        return None
    return proc.stdout if proc.returncode == 0 else None


def toplevel(cwd: Path) -> Path | None:
    out = run(["rev-parse", "--show-toplevel"], cwd)
    return Path(out.strip()).resolve() if out else None


def user_name(cwd: Path) -> str | None:
    out = run(["config", "user.name"], cwd)
    return out.strip() or None if out else None
```

```python
"""Locate the ADR directory, load ADRs, resolve references and write files."""

import datetime as dt
import os
import re
import tempfile
import tomllib
import unicodedata
from collections.abc import Iterable, Iterator, Mapping
from dataclasses import dataclass
from importlib.resources import files
from pathlib import Path

from adrinaline import git
from adrinaline.frontmatter import flow, render, split
from adrinaline.model import (
    FILENAME_RE,
    TRANSITIONS,
    Adr,
    AdrError,
    Finding,
    Status,
    parse_adr,
)

__all__ = ["flow"]


@dataclass(frozen=True)
class Location:
    dir: Path
    root: Path | None
    template: Path


@dataclass
class AdrSet:
    adrs: list[Adr]
    problems: list[Finding]
    numbers: set[int]


def _ancestors(start: Path, top: Path | None) -> Iterator[Path]:
    for directory in (start, *start.parents):
        yield directory
        if directory == top:
            return


def _config_table(directory: Path) -> dict | None:
    dedicated = directory / ".adrinaline.toml"
    if dedicated.is_file():
        return tomllib.loads(dedicated.read_text(encoding="utf-8"))
    pyproject = directory / "pyproject.toml"
    if pyproject.is_file():
        table = tomllib.loads(pyproject.read_text(encoding="utf-8"))
        return table.get("tool", {}).get("adrinaline")
    return None


def locate(cwd: Path, env: Mapping[str, str], explicit: Path | None = None) -> Location:
    root = git.toplevel(cwd)
    table: dict = {}
    base = cwd
    for directory in _ancestors(cwd, root):
        found = _config_table(directory)
        if found:
            table, base = found, directory
            break
    adr_dir_file = next(
        (d / ".adr-dir" for d in _ancestors(cwd, root) if (d / ".adr-dir").is_file()), None
    )
    if explicit is not None:
        directory = cwd / explicit
    elif env.get("ADR_DIR"):
        directory = cwd / env["ADR_DIR"]
    elif "dir" in table:
        directory = base / table["dir"]
    elif adr_dir_file is not None:
        directory = adr_dir_file.parent / adr_dir_file.read_text(encoding="utf-8").strip()
    else:
        directory = (root or cwd) / "docs" / "adr"
    directory = directory.resolve()
    template = (base / table["template"]) if "template" in table else directory / ".template.md"
    return Location(directory, root, template.resolve())


def no_dir(loc: Location) -> AdrError:
    return AdrError(
        "no-adr-dir", f"no ADR directory at {loc.dir}; run `adr init`", dir=str(loc.dir)
    )


def parse_all(items: Iterable[tuple[Path, str]]) -> AdrSet:
    adrs: list[Adr] = []
    problems: list[Finding] = []
    numbers: set[int] = set()
    for path, text in items:
        name = path.name
        if name.startswith(".") or name == "README.md":
            continue
        match = FILENAME_RE.match(name)
        if not match:
            problems.append(
                Finding("bad-filename", "warning", str(path), f"{name}: not NNNN-slug.md, ignored")
            )
            continue
        numbers.add(int(match[1]))
        try:
            adrs.append(parse_adr(path, text))
        except AdrError as exc:
            problems.append(Finding(exc.code, "error", str(path), exc.message))
    adrs.sort(key=lambda adr: (adr.number, adr.slug))
    return AdrSet(adrs, problems, numbers)


def load(loc: Location) -> AdrSet:
    if not loc.dir.is_dir():
        raise no_dir(loc)
    paths = sorted(p for p in loc.dir.iterdir() if p.is_file())
    return parse_all((p, p.read_text(encoding="utf-8")) for p in paths)


def resolve(adrs: list[Adr], ref: str) -> Adr:
    ref = ref.strip()
    if ref.isdigit():
        hits = [adr for adr in adrs if adr.number == int(ref)]
    else:
        hits = [adr for adr in adrs if ref.lower() in adr.slug]
    if not hits:
        raise AdrError("not-found", f"no ADR matches {ref!r}", ref=ref)
    if len(hits) > 1:
        names = [adr.path.name for adr in hits]
        raise AdrError(
            "ambiguous", f"{ref!r} matches {', '.join(names)}", ref=ref, candidates=names
        )
    return hits[0]


def atomic_write(path: Path, text: str) -> None:
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="") as handle:
            handle.write(text)
        os.replace(tmp, path)
    except BaseException:
        Path(tmp).unlink(missing_ok=True)
        raise


def save(adr: Adr) -> None:
    adr.text = render(adr.meta, adr.body)
    atomic_write(adr.path, adr.text)


def set_relation(adr: Adr, name: str, numbers: Iterable[int]) -> None:
    values = sorted(set(numbers))
    adr.relations[name] = values
    if values:
        adr.meta[name] = flow(values)
    else:
        adr.meta.pop(name, None)


def set_status(adr: Adr, status: Status, today: dt.date) -> None:
    adr.status = status
    adr.date = today
    adr.meta["status"] = status.value
    adr.meta["date"] = today


def transition(adr: Adr, to: Status, *, force: bool = False, today: dt.date) -> None:
    if not force and (adr.status, to) not in TRANSITIONS:
        raise AdrError(
            "invalid-transition",
            f"{adr.id}: cannot change status from {adr.status} to {to} (use --force to repair)",
            current=adr.status.value,
            requested=to.value,
        )
    set_status(adr, to, today)


def slugify(title: str) -> str:
    ascii_title = unicodedata.normalize("NFKD", title).encode("ascii", "ignore").decode()
    return re.sub(r"[^a-z0-9]+", "-", ascii_title.lower()).strip("-") or "untitled"


def data_text(name: str) -> str:
    return (files("adrinaline") / "data" / name).read_text(encoding="utf-8")


def template_text(loc: Location) -> str:
    if loc.template.is_file():
        return loc.template.read_text(encoding="utf-8")
    return data_text("template.md")


def render_new(
    template: str,
    title: str,
    status: Status,
    today: dt.date,
    body: str | None,
    tags: list[str],
) -> str:
    meta, template_body = split(template.replace("{title}", title))
    meta["status"] = status.value
    meta["date"] = today
    if tags:
        meta["tags"] = flow(sorted({*meta.get("tags", []), *tags}))
    if body is not None:
        template_body = f"# {title}\n\n{body.strip()}\n"
    return render(meta, template_body)


def numbers_in(directory: Path) -> set[int]:
    return {int(m[1]) for p in directory.iterdir() if (m := FILENAME_RE.match(p.name))}


def next_number(loc: Location) -> tuple[int, dict[int, str]]:
    return max(numbers_in(loc.dir), default=0) + 1, {}


def create_file(directory: Path, number: int, slug: str, text: str) -> Path:
    while True:
        if not any(directory.glob(f"{number:04d}-*.md")):
            path = directory / f"{number:04d}-{slug}.md"
            try:
                with path.open("x", encoding="utf-8", newline="") as handle:
                    handle.write(text)
                return path
            except FileExistsError:
                pass
        number += 1
```

```python
"""Human and JSON output, the error envelope and exit codes."""

import json
import sys
from pathlib import Path
from typing import Any

from adrinaline.model import STORED_RELATIONS, Adr, AdrError

EXIT_OK = 0
EXIT_FINDINGS = 1
EXIT_DOMAIN = 3

_KNOWN_KEYS = {"status", "date", "tags", "scope", *STORED_RELATIONS}


def dumps(data: Any) -> str:
    return json.dumps(data, ensure_ascii=False, indent=2, default=str)


class Out:
    def __init__(self, *, json_mode: bool, quiet: bool, base: Path) -> None:
        self.json_mode = json_mode
        self.quiet = quiet
        self.base = base.resolve()

    def rel(self, path: Path) -> str:
        try:
            return path.resolve().relative_to(self.base).as_posix()
        except ValueError:
            return str(path)

    def result(self, data: Any, text: str) -> None:
        if self.json_mode:
            sys.stdout.write(dumps(data) + "\n")
        elif not self.quiet and text:
            sys.stdout.write(text if text.endswith("\n") else text + "\n")

    def note(self, text: str) -> None:
        if not self.quiet:
            print(text, file=sys.stderr)


def adr_dict(
    adr: Adr,
    out: Out,
    *,
    relations: dict[str, list[int]] | None = None,
    body: bool = False,
    **extra: Any,
) -> dict[str, Any]:
    data: dict[str, Any] = {
        "number": adr.number,
        "id": adr.id,
        "slug": adr.slug,
        "title": adr.title,
        "status": adr.status.value,
        "date": adr.date.isoformat(),
        "path": out.rel(adr.path),
        "tags": list(adr.tags),
        "scope": list(adr.scope),
        "relations": relations
        if relations is not None
        else {name: nums for name, nums in adr.relations.items() if nums},
        "meta": {k: v for k, v in adr.meta.items() if k not in _KNOWN_KEYS},
    }
    if body:
        data["body"] = adr.body
    return data | extra


def error(err: AdrError, json_mode: bool) -> int:
    if json_mode:
        envelope = {"error": {"code": err.code, "message": err.message, "details": err.details}}
        sys.stdout.write(dumps(envelope) + "\n")
    else:
        print(f"adr: {err.code}: {err.message}", file=sys.stderr)
    return EXIT_DOMAIN
```

```python
"""Validation rules for `adr check`. Each rule returns Finding objects."""

from collections import defaultdict

from adrinaline.model import Finding
from adrinaline.repo import AdrSet


def _duplicates(s: AdrSet) -> list[Finding]:
    groups = defaultdict(list)
    for adr in s.adrs:
        groups[adr.number].append(adr)
    return [
        Finding(
            "duplicate-number",
            "error",
            str(adr.path),
            f"{adr.id} is used by {', '.join(a.path.name for a in group)}; fix with `adr renumber`",
        )
        for group in groups.values()
        if len(group) > 1
        for adr in group
    ]


def _gaps(s: AdrSet) -> list[Finding]:
    return [
        Finding("number-gap", "warning", "", f"{n:04d} is missing")
        for n in range(1, max(s.numbers, default=0))
        if n not in s.numbers
    ]


def run_checks(s: AdrSet, *, template_exists: bool) -> list[Finding]:
    findings = [*s.problems, *_duplicates(s), *_gaps(s)]
    if not template_exists:
        findings.append(
            Finding("no-template", "warning", "", "template is missing; `adr init` recreates it")
        )
    return sorted(findings, key=lambda f: (f.path, f.code))
```

````markdown
---
name: adr
description: Record, find and respect Architecture Decision Records with the `adr` CLI. Use before changing architecture, adding a dependency, changing a public interface, data format or security control, and whenever a task touches files governed by an ADR.
---

# Architecture Decision Records with `adr`

ADRs are Markdown files in the repository (usually `docs/adr/NNNN-slug.md`) with YAML frontmatter. `adr` manages them. Every command accepts `--json`.

## At the start of a task

1. Run `adr prime` to see the decisions in force.
2. Before editing a file, run `adr for <path>` and follow the ADRs it lists.

## When to write an ADR

Write one for decisions that are expensive to reverse: architecture, frameworks and dependencies, data formats and storage, public interfaces, security and compliance controls. Do not write one for routine implementation choices.

## Writing one

```bash
adr new "Use PostgreSQL for persistence" --tag storage --body-file - <<'EOF'
## Context and Problem Statement

…

## Considered Options

* PostgreSQL
* SQLite

## Decision Outcome

Chosen option: "PostgreSQL", because …

### Consequences

* Good, because …
* Bad, because …
EOF
```

New ADRs start as `proposed`. A human accepts them with `adr accept N`.

## Changing a decision

Never rewrite the decision of an accepted ADR. Instead:

* Replace it: `adr new "…" --supersedes N`
* Change part of it: `adr new "…" --amends N`
* Record a prerequisite or a related decision: `adr link NEW depends-on N`, `adr link NEW relates-to N`

## Before finishing

Run `adr check`. Fix every error it reports.
````

```python
"""Command-line interface: argparse wiring and one cmd_<name> function per command."""

import argparse
import datetime as dt
import os
import shlex
import subprocess
import sys
from collections.abc import Callable, Mapping
from dataclasses import asdict, dataclass
from pathlib import Path

from adrinaline import __version__, git, repo
from adrinaline.check import run_checks
from adrinaline.frontmatter import render, split
from adrinaline.model import Adr, AdrError, Status
from adrinaline.output import EXIT_FINDINGS, EXIT_OK, Out, adr_dict, error

AGENT_HINT = "Agents: run `adr prime` first. Every command accepts --json."


@dataclass
class Ctx:
    args: argparse.Namespace
    loc: repo.Location
    out: Out
    cwd: Path

    def load(self) -> repo.AdrSet:
        return repo.load(self.loc)


def today() -> dt.date:
    return dt.date.today()


def list_line(adr: Adr) -> str:
    return f"{adr.id}  {adr.status:<10}  {adr.date}  {adr.title}"


def show_text(adr: Adr, relations: dict[str, list[int]], by_number: dict[int, Adr], out: Out) -> str:
    lines = [f"{adr.id} {adr.title}", f"status: {adr.status}   date: {adr.date}"]
    if adr.tags:
        lines.append("tags: " + ", ".join(adr.tags))
    if adr.scope:
        lines.append("scope: " + ", ".join(adr.scope))
    for name, numbers in relations.items():
        labels = [
            f"{n:04d} {by_number[n].title}" if n in by_number else f"{n:04d} (missing)"
            for n in numbers
        ]
        lines.append(f"{name}: " + "; ".join(labels))
    lines += [f"path: {out.rel(adr.path)}", "", adr.body.strip()]
    return "\n".join(lines)


def cmd_init(ctx: Ctx) -> None:
    loc, force = ctx.loc, ctx.args.force
    loc.dir.mkdir(parents=True, exist_ok=True)
    written: list[Path] = []
    if force or not loc.template.exists():
        loc.template.parent.mkdir(parents=True, exist_ok=True)
        repo.atomic_write(loc.template, repo.data_text("template.md"))
        written.append(loc.template)
    first = next(loc.dir.glob("0001-*.md"), None)
    if force or first is None:
        target = first or loc.dir / "0001-record-architecture-decisions.md"
        meta, body = split(repo.data_text("0001.md"))
        meta["date"] = today()
        if name := git.user_name(ctx.cwd):
            meta["decision-makers"] = repo.flow([name])
        repo.atomic_write(target, render(meta, body))
        written.append(target)
    paths = [ctx.out.rel(p) for p in written]
    text = "\n".join(f"wrote {p}" for p in paths) or "already initialised"
    ctx.out.result({"dir": ctx.out.rel(loc.dir), "written": paths}, text)


def _edit(path: Path) -> None:
    editor = os.environ.get("VISUAL") or os.environ.get("EDITOR") or "vi"
    subprocess.run([*shlex.split(editor), str(path)], check=False)


def cmd_new(ctx: Ctx) -> None:
    args, loc = ctx.args, ctx.loc
    if not loc.dir.is_dir():
        raise repo.no_dir(loc)
    body = None
    if args.body_file == "-":
        body = sys.stdin.read()
    elif args.body_file:
        body = Path(args.body_file).read_text(encoding="utf-8")
    status = Status.ACCEPTED if args.accepted else Status.PROPOSED
    text = repo.render_new(repo.template_text(loc), args.title, status, today(), body, args.tag)
    number, skipped = repo.next_number(loc)
    path = repo.create_file(loc.dir, number, repo.slugify(args.title), text)
    for n, ref in sorted(skipped.items()):
        ctx.out.note(f"skipped {n:04d}, taken on {ref}")
    if args.edit:
        _edit(path)
    adr = repo.parse_adr(path, path.read_text(encoding="utf-8"))
    skipped_json = {f"{n:04d}": ref for n, ref in sorted(skipped.items())}
    ctx.out.result(adr_dict(adr, ctx.out, skipped=skipped_json), ctx.out.rel(path))


def cmd_show(ctx: Ctx) -> None:
    adrs = ctx.load().adrs
    adr = repo.resolve(adrs, ctx.args.ref)
    if ctx.args.raw:
        ctx.out.result({"path": ctx.out.rel(adr.path), "text": adr.text}, adr.text)
        return
    relations = {name: nums for name, nums in adr.relations.items() if nums}
    by_number = {a.number: a for a in adrs}
    ctx.out.result(
        adr_dict(adr, ctx.out, relations=relations, body=True),
        show_text(adr, relations, by_number, ctx.out),
    )


def cmd_list(ctx: Ctx) -> None:
    args = ctx.args
    adrs = [
        adr
        for adr in ctx.load().adrs
        if (not args.status or adr.status in args.status)
        and (not args.tag or set(args.tag) & set(adr.tags))
    ]
    ctx.out.result([adr_dict(a, ctx.out) for a in adrs], "\n".join(list_line(a) for a in adrs))


def cmd_index(ctx: Ctx) -> None:
    adrs = ctx.load().adrs
    rows = ["| ADR | Title | Status | Date |", "|---|---|---|---|"]
    rows += [
        f"| [{a.id}]({a.path.name}) | {a.title.replace('|', '\\|')} | {a.status} | {a.date} |"
        for a in adrs
    ]
    ctx.out.result([adr_dict(a, ctx.out) for a in adrs], "\n".join(rows))


def _set_status(to: Status) -> Callable[[Ctx], None]:
    def cmd(ctx: Ctx) -> None:
        adr = repo.resolve(ctx.load().adrs, ctx.args.ref)
        before = adr.status
        repo.transition(adr, to, force=ctx.args.force, today=today())
        repo.save(adr)
        ctx.out.result(adr_dict(adr, ctx.out), f"{adr.id} {adr.title}: {before} -> {to}")

    return cmd


def cmd_check(ctx: Ctx) -> int:
    findings = run_checks(ctx.load(), template_exists=ctx.loc.template.is_file())
    failed = any(f.severity == "error" for f in findings) or (ctx.args.strict and bool(findings))
    rows = [asdict(f) | {"path": ctx.out.rel(Path(f.path)) if f.path else ""} for f in findings]
    text = "\n".join(f"{r['severity']}: {r['code']}: {r['message']}" for r in rows) or "ok"
    ctx.out.result({"ok": not failed, "findings": rows}, text)
    return EXIT_FINDINGS if failed else EXIT_OK


def cmd_skill(ctx: Ctx) -> None:
    text = repo.data_text("SKILL.md")
    ctx.out.result({"skill": text}, text)


def build_parser() -> argparse.ArgumentParser:
    common = argparse.ArgumentParser(add_help=False)
    common.add_argument("--json", action="store_true", help="print one JSON document on stdout")
    common.add_argument("--dir", type=Path, help="ADR directory (overrides discovery)")
    common.add_argument("-q", "--quiet", action="store_true", help="no output on success")

    parser = argparse.ArgumentParser(
        prog="adr", description="Git-native Architecture Decision Records.", epilog=AGENT_HINT
    )
    parser.add_argument("--version", action="version", version=f"adr {__version__}")
    sub = parser.add_subparsers(dest="command", required=True, metavar="COMMAND")

    def add(name: str, func: Callable[[Ctx], int | None], help_: str) -> argparse.ArgumentParser:
        p = sub.add_parser(name, parents=[common], help=help_, description=help_)
        p.set_defaults(func=func)
        return p

    p = add("init", cmd_init, "create the ADR directory, template and ADR 0001")
    p.add_argument("--force", action="store_true", help="overwrite the template and ADR 0001")

    p = add("new", cmd_new, "create a new ADR")
    p.add_argument("title")
    p.add_argument("--accepted", action="store_true", help="create as accepted")
    p.add_argument("--tag", action="append", default=[])
    p.add_argument("--body-file", metavar="PATH", help="body below the title ('-' = stdin)")
    p.add_argument("--edit", action="store_true", help="open $VISUAL/$EDITOR afterwards")

    p = add("show", cmd_show, "show one ADR")
    p.add_argument("ref")
    p.add_argument("--raw", action="store_true", help="print the file verbatim")

    p = add("list", cmd_list, "list ADRs")
    p.add_argument("--status", action="append", choices=[s.value for s in Status])
    p.add_argument("--tag", action="append")

    add("index", cmd_index, "print a Markdown index table")

    for name, to in (
        ("accept", Status.ACCEPTED),
        ("reject", Status.REJECTED),
        ("deprecate", Status.DEPRECATED),
    ):
        p = add(name, _set_status(to), f"mark an ADR as {to}")
        p.add_argument("ref")
        p.add_argument("--force", action="store_true", help="allow any transition (repairs)")

    p = add("check", cmd_check, "validate all ADRs")
    p.add_argument("--strict", action="store_true", help="fail on warnings too")

    add("skill", cmd_skill, "print the bundled agent skill (SKILL.md)")
    return parser


def main(
    argv: list[str] | None = None,
    cwd: Path | None = None,
    env: Mapping[str, str] | None = None,
) -> int:
    args = build_parser().parse_args(argv)
    cwd = (cwd or Path.cwd()).resolve()
    env = os.environ if env is None else env
    try:
        loc = repo.locate(cwd, env, args.dir)
        out = Out(json_mode=args.json, quiet=args.quiet, base=loc.root or cwd)
        return args.func(Ctx(args, loc, out, cwd)) or EXIT_OK
    except AdrError as exc:
        return error(exc, args.json)


def run() -> None:
    sys.exit(main())
```
